# hello

`hello` is the smallest useful entry: it reads one optional `name` string and returns a JSON greeting.

It is also the only tool kept by `scripts/clean_to_template.py`, so a freshly cleaned template still loads, lists one tool, and answers a real call.

Replace it with your first real tool, then update `skill.yaml`, this help file, and `examples/debug/hello.args.json` together.
